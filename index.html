Conceito 1 · o modelo relacional

Tabelas que se relacionam por chaves

Cada tabela guarda um assunto. As linhas são os registros; as colunas, os atributos. A chave primária identifica cada linha, e a chave estrangeira aponta para a linha de outra tabela.

Tabelaum assunto: Cliente, Pedido, Produto.
Linhaum registro: um cliente específico.
Colunaum atributo com tipo: nome NVARCHAR(100).
PKvalor único que identifica a linha.
FKvalor que precisa existir na PK de outra tabela.

Passe o mouse ou toque em um cliente para ver os pedidos dele.

Cliente
PK id_clientenome
Pedido
PK id_pedidoFK id_clientestatus

Os 5 subconjuntos da SQL

          
A cor de cada subconjunto é a mesma usada no terminal e no Raio-X.

          

            
DDL
Data Definition Language
Define a estrutura dos objetos.
CREATE · ALTER · DROP · TRUNCATE

            
DML
Data Manipulation Language
Manipula os dados das tabelas.
INSERT · UPDATE · DELETE

            
DQL
Data Query Language
Consulta e extrai dados.
SELECT

            
DCL
Data Control Language
Controla permissões.
GRANT · REVOKE · DENY

            
DTL/TCL
Transaction Control
Controla transações.
BEGIN TRAN · COMMIT · ROLLBACK

          

          
Ponto de prova
CREATE e ALTER TABLE são DDL; INSERT, UPDATE e DELETE são DML; SELECT é estritamente DQL.

Ordem lógica de processamento do SELECT

          
Você escreve SELECT primeiro, mas o servidor processa nesta ordem. Isso explica por que o alias do SELECT não existe no WHERE e por que agregação não cabe no WHERE.

          

            1 · FROM / JOINmonta as linhas→
            2 · WHEREfiltra linhas→
            3 · GROUP BYforma grupos→
            4 · HAVINGfiltra grupos→
            5 · SELECTprojeta colunas→
            6 · DISTINCT→
            7 · ORDER BYordena→
            8 · TOP
          

        


        

          
Filtros e operações de conjunto

          

            
OperadorO que faz

            
              
LIKE% = zero ou mais caracteres; _ = exatamente um.

              
INpertinência a uma lista; substitui vários OR.

              
BETWEENintervalo inclusivo (mínimo e máximo entram).

              
UNIONempilha resultados e remove duplicatas.

              
UNION ALLempilha mantendo duplicatas (mais rápido).

              
INTERSECTsó o que está nas duas consultas.

              
EXCEPTo que está na 1ª e não está na 2ª.

            

          
Ponto de prova
Operações de conjunto exigem o mesmo número de colunas, com tipos compatíveis e na mesma ordem.

        


        

          
WHERE × HAVING

          

            
WHERE
Filtra linhas individuais antes do agrupamento.
Não aceita SUM, AVG, COUNT, MAX, MIN.

            
HAVING
Filtra grupos depois do GROUP BY.
É onde ficam as condições com agregação.

          

          
SELECT id_departamento, AVG(salario) AS Media_Salarial
FROM Funcionario
WHERE data_admissao >= '2020-01-01'   -- filtra LINHAS antes do agrupamento
GROUP BY id_departamento
HAVING AVG(salario) > 3000;          -- filtra os GRUPOS resultantes

          
Ponto de prova
Toda coluna não agregada listada no SELECT precisa constar no GROUP BY (Msg 8120). O simulador reproduz esse erro.

Subconsultas e Stored Procedures

          

            
TipoCaracterística

            
              
SimplesExecutada uma vez; o resultado alimenta a consulta externa.

              
CorrelacionadaReferencia a consulta externa e é reavaliada linha a linha. Cuidado com desempenho.

              
Tabela derivadaSubconsulta no FROM, com alias, usada como tabela temporária.

            

          

            
Desempenho
Reutiliza o plano de execução pré-compilado em memória.

            
Segurança
GRANT EXECUTE na procedure sem dar acesso direto às tabelas.

            
Manutenção
A regra de negócio fica centralizada no servidor.

Compatibilidade do simulador

          
O motor é SQLite rodando no navegador. Uma camada traduz a sintaxe T-SQL mais usada na disciplina e reproduz mensagens de erro do SQL Server.

          

            
Você escreve (T-SQL)Situação

            
              
IDENTITY(1,1), GETDATE(), TOP n, LEN, ISNULL, YEAR/MONTH/DAY, DATEDIFF, DATEADD, CHARINDEX, CONVERT, GO, N'texto'Traduzido automaticamente

              
INNER / LEFT / RIGHT / FULL / CROSS JOIN, UNION, INTERSECT, EXCEPT, subconsultas, CASE, EXISTS, views, índicesNativo

              
BEGIN TRAN, COMMIT, ROLLBACK, SAVE TRANNativo (sem transações aninhadas)

              
CREATE/ALTER/DROP PROCEDURE, EXEC, DECLARE, SET @var, PRINTSimulado

              
GRANT, REVOKE, DENY; sp_help, sp_tables, sp_helptext, sp_helprotect, sp_stored_proceduresSimulado (usuário único)

              
Erro 8120 (coluna fora do GROUP BY), modo seguro para UPDATE/DELETE sem WHEREEmulado para se comportar como o SQL Server

              
ALTER COLUMN, ADD CONSTRAINT, IF/WHILE, TRY/CATCH, triggers T-SQLNão suportado (mensagem explicativa)

              
DECIMALAceito, mas armazenado como número real. No SQL Server o DECIMAL é exato.
